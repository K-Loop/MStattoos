# MS TATTOO STUDIO & ART ACADEMY

An editorial, high-fashion web sanctuary and portfolio experience for **MS Tattoo Studio & Art Academy**.

---

## Highlights
- **Editorial Design System**: Crafted in warm soft canvas tones (`#F7F6F2`, `#EFEDE7`, `#D8D6D0`, `#111111`) with classical serif typography (`Playfair Display`, `Cinzel`).
- **Official Brand Mark**: Integrated official MS Tattoo Studio monogram and logo assets.
- **Authentic Artwork Collection**: 49 authentic studio pieces across 6 streamlined disciplines:
  - *Tattoos*
  - *Pencil & Graphite Art*
  - *Paintings & Murals*
  - *Crystal Stone Art*
  - *Glitter Surprise Art*
  - *Wood Burning & Resin Art*
- **Studio in Motion (Process Reels)**: Interactive video reels showcasing live glitter reveals, pencil portrait detailing, and resin pours.
- **Bespoke Commission & Registration System**: Interactive modals for custom commissions and academy course enrollments with real-time tariff calculations.
- **Admin Management Portal**: Order and application management with secure PIN protection and Excel export.

---

## Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: React Icons (Feather, Remix, FontAwesome)

---

## Local Development
```bash
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
